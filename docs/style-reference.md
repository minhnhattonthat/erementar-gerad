# Style reference - Erementar Gerad (GBA)

Light, comic adventure based on the anime/manga *Erementar Gerad*. The pilot (batch b000: prologue, the merchant
escort) was inserted and checked in-game; match its voice. Honorifics are KEPT (Cou-san, Ren-chan, Coud-sama).

## Voices
| Character | Voice | Calls others |
|---|---|---|
| Coud (クー/クード) | brash, warm-hearted teen boy; casual, slangy ("Let's show 'em", "I'm beat~"); calls himself "the great Coud-sama" when boasting | Ren, Cisqua, Ro, Kea |
| Ren (レン) | quiet, gentle, short sentences; sincere | Cou |
| Cisqua (シスカ) | Arc Aile protection officer; brisk, polite-but-bossy, money-minded schemer; occasional sing-song "~" | Cou-san, Ren-san, Rowen-kun if JP has it |
| Rowen (ローウェン) | polite, level-headed young man; the voice of reason | Senpai (= Cisqua), Cou, Kea |
| Kea (キーア) | Rowen's Edel Raid; sassy, teasing, food-loving; calls herself "big sister Kea" (キーアねェさん) | Cou, Ro |
| Merchant (Kansai dialect) | folksy, dropped g's ("savin'", "ya", "ain't"), friendly huckster; never phonetic dialect spelling beyond that | "little lady" (ネェちゃん) |
| Edel Raid girl, prologue (～のヨ) | childish, whiny emphasis ("you know!") | |

## Conventions
- Katakana stress words (ジョーシキ, サンゾク) are just normal English words; no caps.
- 「…」 inside dialogue -> "...". 『…』 (quoted term) -> "...".
- …… -> "..." (one ellipsis per pause; "......" only for a long silent beat line like "......").
- Stretched vowels (～, ー at word end) -> "~" only where the line is playful (Cisqua's "everyone~"); otherwise a
  normal word ("Phew", "Whew").
- Stutters: "N-no", "L-little lady".
- Shouts: "?!" (not "!?"); keep "!!" where JP has ！！.
- Numbers: Arabic digits ("527 Ganee", "2000 Ganee").
- Do not add line breaks: the build wraps text to the box. One string = one text box (3 lines max).

## Approved examples (JP -> EN)
- あります。大ありデス！先ほど気になっておサイフの中を確認しましたら… -> There is. A huge one! I was worried, so I just checked our wallet, and...
- ああ…たとえアレがあるとしてもこれでは宿代どころか、キーアのおやつ分にも足りません… -> Oh... Even with "that" to fall back on, this won't cover an inn, or even Kea's snacks...
- この元気のカタマリ、クード様はそうやすやすとギブアップなんかしないぜ？ -> I'm the great Coud-sama, a bundle of energy! I don't give up that easily, got it?
- 森ン中であんなんにおそわれたらオレなんてイチコロやんか？ほんま助かったで。 -> If those guys jumped me in the middle of the woods, I'd be a goner, y'know? You really saved my hide.
- 発言によっちゃ、キーアねェさんがだまってないわよ！？ -> Depending on what you say, big sister Kea won't keep quiet!
- ８０ガネーせしめてやりましたッ！サンゾクさんには悪いですケド。 -> We squeezed 80 Ganee out of them! Sorry, Mister Bandits.

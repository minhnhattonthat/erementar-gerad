Erementar Gerad: The Sealed Song (GBA) - English translation patch v{version}
==============================================================================

Unofficial fan translation of "Erementar Gerad: Tozasareshi Uta" (Tomy, 2005) for the Game Boy Advance.
This is a patch only. No ROM is included or will be provided.

Applying the patch
------------------
Apply the .bps file to your own dump of the Japanese ROM with Flips, beat, or an online patcher
(e.g. Rom Patcher JS). The patched game is the same size as the original.

Required base ROM (Japanese release, unmodified):
  File size: {size} bytes
  CRC32:  {crc}
  MD5:    {md5}
  SHA-1:  {sha1}
Patched ROM CRC32: {patched_crc}

What is translated
------------------
- All story dialogue, menus, items, skill descriptions, shop and arena text, and the staff credits.
- Dialogue name tags, battle name plates, enemy names, skill/attack/item name banners, menu tabs,
  info-box labels, the battle tutorial pages, and the title logo.
- A new variable-width English font (two letters per game glyph) gives about 35 letters per line.

Notes
-----
- Tested in Mesen 2. Start a NEW game on a cold boot; savestates made with the Japanese ROM will not work.
- Japanese honorifics (-san, -chan, Senpai) are kept. Names follow the English anime release where it exists.
- Debug/developer screens are left as they were.

Known issues
------------
- See the project notes; please report text that overflows or looks wrong, with a savestate if you can.

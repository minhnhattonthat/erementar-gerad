## Rulings (asked of the user 2026-10-14)
- Honorifics: kept, hyphenated (Cisqua-san). Name order: as the game gives it.
- Romanisation source: official anime English (Geneon dub/subs) where it exists; Hepburn for game-only names.
- Credits: English.
- Graphics text (title logo, menus, banners): all in scope, translate.
- Abbreviations: full names and terms everywhere; prefer engine changes over shortening.
- Specs/plans pre-approved: keep going through checkpoints, report at milestones.

## Style rules
- Punctuation map: 「」 -> "...", 『』 -> '...', ・・・ / … -> ..., ！？ -> ?!, ～ at line end -> ~ or drop.
- Kansai-dialect shopkeeper (やな/やで/わ): casual folksy English, not phonetic dialect spelling.
